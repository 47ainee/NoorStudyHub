Normalization

Learn 1NF, 2NF, 3NF and BCNF with simple explanations and examples.

💡 Did You Know?

Normalization helps organize data efficiently by reducing duplication and improving data consistency.

📖 What is Normalization?

Normalization is the process of organizing data in a database to reduce redundancy and improve data integrity. It divides large tables into smaller related tables.

⭐ Why do we use Normalization?

  • Reduce data redundancy
  • Improve consistency
  • Avoid update anomalies
  • Save storage space
  • Make databases easier to maintain

📚 Normal Forms

Normal Form Description
1NF Remove repeating groups and store atomic values.
2NF Remove partial dependency.
3NF Remove transitive dependency.
BCNF Every determinant must be a candidate key.

1️⃣ First Normal Form (1NF)

A table is in First Normal Form when every column contains only atomic (single) values and there are no repeating groups. 


StudentID

Name

Subject

2️⃣ Second Normal Form (2NF)

A table is in Second Normal Form when it is already in 1NF and all non-key attributes depend on the whole primary key.

3️⃣ Third Normal Form (3NF)

A table is in Third Normal Form when it is already in 2NF and has no transitive dependency.

4️⃣ Boyce-Codd Normal Form (BCNF)

BCNF is a stronger version of 3NF. Every determinant in the table must be a candidate key.

💻 Example


Student(ID, Name, Department)

Department(DepartmentID, DepartmentName)

⭐ Advantages of Normalization

  • Less duplicate data
  • Better consistency
  • Easy updates
  • Improved database performance
  • Efficient storage

❌ Common Mistakes

  • Confusing 2NF and 3NF
  • Ignoring functional dependency
  • Creating unnecessary tables
  • Using repeated values
