DOM Manipulation

Learn how JavaScript interacts with HTML elements using DOM methods and examples.

💡 Did You Know?

DOM stands for Document Object Model. It allows JavaScript to access and change HTML elements dynamically.

📖 What is DOM?

DOM (Document Object Model) is a programming interface that represents an HTML document as a tree structure. JavaScript uses DOM to interact with webpage elements.

⭐ Why do we use DOM?

  • Change HTML content
  • Change CSS styles
  • Add or remove elements
  • Create interactive webpages
  • Handle user actions

🌳 DOM Tree Structure

HTML elements are organized in a tree-like structure where each element is called a node. 


Document

 └── HTML

      ├── Head

      └── Body

           ├── Heading

           └── Paragraph

📝 Selecting HTML Elements

JavaScript provides different methods to select elements from HTML.

🎯 getElementById()

Selects an element using its ID. 


document.getElementById("title");

🎯 querySelector()

Selects the first matching HTML element. 


document.querySelector(".box");

🎯 querySelectorAll()

Selects all matching elements. 


document.querySelectorAll("p");

✏ Changing HTML Content

JavaScript can change the content of HTML elements using innerHTML. 


document.getElementById("heading").innerHTML="Hello";

🎨 Changing CSS Style

JavaScript can also change CSS styles dynamically. 


document.getElementById("box").style.color="red";

➕ Creating New Elements

JavaScript can create new HTML elements using createElement(). 


let heading = document.createElement("h1");

🗑 Removing Elements

Elements can be removed from a webpage using remove(). 


element.remove();

❌ Common Mistakes

  • Using wrong element ID
  • Running JavaScript before HTML loads
  • Missing brackets
  • Selecting elements that do not exist
