📘 HTML Chapter 5

Semantic HTML

Learn Semantic HTML tags and build SEO-friendly, well-structured webpages.

💡 Did You Know?

Semantic HTML helps search engines and browsers understand the structure of a webpage. It also improves SEO and accessibility.

📖 What is Semantic HTML?

Semantic HTML uses meaningful tags that clearly describe the purpose of the content. Instead of using only <div> tags, semantic tags explain what each section of the webpage represents.

📚 Semantic vs Non-Semantic Tags

Semantic Tags Non-Semantic Tags
<header> <div>
<nav> <span>
<main> <div>
<article> <span>
<section> <div>
<footer> <div>

⭐ Common Semantic Tags

Tag Purpose
<header> Top section of a webpage
<nav> Navigation menu
<main> Main webpage content
<section> Groups related content
<article> Independent article or blog
<aside> Sidebar content
<footer> Bottom section of webpage

💻 Example


<header>

Website Header

</header>

<nav>

Home | About | Contact

</nav>

<main>

<section>

Welcome to my website.

</section>

</main>

<footer>

Copyright 2026

</footer>

🎯 Advantages of Semantic HTML

  • Improves SEO
  • Better Accessibility
  • Easy to Read
  • Professional Code Structure
  • Easy Maintenance

❌ Common Mistakes

  • Using div everywhere
  • Incorrect semantic tag placement
  • Multiple main tags
  • Using footer inside unrelated elements

🎤 Interview Questions

Q1: What is Semantic HTML?
Semantic HTML uses meaningful tags that describe webpage content.

Q2: Name four Semantic Tags.
header, nav, section, footer

Q3: Why is Semantic HTML important?
It improves SEO, accessibility and code readability.

Q4: Which tag contains the main content?
<main>
