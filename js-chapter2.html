Variables & Data Types

Learn JavaScript variables, let, const and different data types with easy examples.

💡 Did You Know?

Variables are like containers that store information in JavaScript. They help programmers save and reuse data in their programs.

📖 What are Variables?

Variables are used to store data values in JavaScript. A variable has a name and a value that can be used throughout a program.

📝 Creating Variables in JavaScript

JavaScript provides three keywords to create variables:

  • var
  • let
  • const

⭐ var Keyword

The var keyword is the old way of declaring variables in JavaScript. Its value can be changed and it has function scope. 


var name = "Noor";

var age = 20;

⭐ let Keyword

The let keyword is used to create variables whose values can be changed later. It has block scope. 


let city = "Rawalpindi";

city = "Lahore";

⭐ const Keyword

The const keyword is used for values that cannot be reassigned after creation. 


const pi = 3.14;

⚖ Difference Between var, let and const

Keyword Description
var Old method, value can be changed
let Modern method, value can be updated
const Value cannot be reassigned

📚 JavaScript Data Types

Data types define what type of value a variable stores.

🔹 Primitive Data Types

  • String
  • Number
  • Boolean
  • Undefined
  • Null
  • BigInt
  • Symbol

🔹 Non-Primitive Data Types

  • Object
  • Array

💻 Example of Data Types


let name = "Noor";

let age = 20;

let student = true;

let marks = [90,85,95];

❌ Common Mistakes

  • Using variable without declaration
  • Using const when value needs to change
  • Writing incorrect variable names
  • Confusing data types

🎤 Interview Questions

Q1: What is a variable in JavaScript?
A variable stores data values that can be used in a program.

Q2: Name three keywords used to declare variables.
var, let and const

Q3: Which keyword creates a constant variable?
const

Q4: What are JavaScript data types?
They define the type of value stored in a variable.
