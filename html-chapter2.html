📘 HTML Chapter 2

HTML Tags & Elements

Learn HTML Tags, Elements and Attributes with easy explanations and examples.

💡 Did You Know?

Every HTML webpage is made up of Tags and Elements. Without tags, a browser cannot understand what to display.

📖 What are HTML Tags?

HTML Tags are predefined keywords enclosed inside angle brackets (< >). They tell the browser how to display content on a webpage. Most HTML tags have an opening tag and a closing tag.

📝 Example of HTML Tags


<h1>Welcome</h1>

<p>This is a paragraph.</p>

<a href="https://google.com">Google</a>

📖 What is an HTML Element?

An HTML Element consists of: Opening Tag + Content + Closing Tag. Example: 


<p>

Hello Noor

</p>

The complete paragraph is called an HTML Element.

📖 What are HTML Attributes?

HTML Attributes provide extra information about HTML Elements. They are always written inside the opening tag. 


<img src="image.jpg" alt="Nature">

⭐ Common HTML Attributes

Attribute Purpose
href Defines a hyperlink
src Specifies image path
alt Alternative image text
class Assigns CSS class
id Unique element identifier
style Inline CSS

📚 Types of HTML Tags

  • Paired Tags → Have opening and closing tags.
  • Empty Tags → Do not require a closing tag.

💻 Examples of Empty Tags


<br>

<hr>

<img>

<input>

🎯 Advantages of HTML Tags

  • Easy to understand
  • Help organize webpage content
  • Supported by every browser
  • Easy to combine with CSS & JavaScript
  • Improve webpage structure

❌ Common Mistakes

  • Forgetting closing tags
  • Incorrect nesting of tags
  • Missing quotation marks in attributes
  • Typing wrong tag names

🎤 Interview Questions

Q1: What is an HTML Tag?
An HTML Tag tells the browser how to display webpage content.

Q2: What is an HTML Element?
Opening Tag + Content + Closing Tag.

Q3: What is an HTML Attribute?
An Attribute provides additional information about an HTML element.

Q4: Name any four HTML Attributes.
href, src, alt, class

⚡ Quick Revision

HTML Tag: Keyword enclosed in < >
HTML Element: Opening Tag + Content + Closing Tag
HTML Attribute: Extra information about an element
Examples: href, src, alt, class, id
