Operators & Expressions

Learn JavaScript operators, expressions and how to perform different operations with examples.

💡 Did You Know?

Operators are symbols that tell JavaScript to perform specific operations on values. They are used in calculations, comparisons and decision making.

📖 What are JavaScript Operators?

JavaScript Operators are special symbols used to perform operations on variables and values. For example, addition, subtraction, comparison and logical operations.

⭐ Types of JavaScript Operators

JavaScript provides different types of operators:

  • Arithmetic Operators
  • Assignment Operators
  • Comparison Operators
  • Logical Operators
  • Increment & Decrement Operators

➕ Arithmetic Operators

Arithmetic operators are used to perform mathematical calculations.

Operator Purpose
+ Addition
- Subtraction
* Multiplication
/ Division
% Modulus (remainder)

💻 Arithmetic Example


let a = 10;

let b = 5;

console.log(a + b);

console.log(a * b);

📝 Assignment Operators

Assignment operators are used to assign values to variables.

Operator Example
= x = 10
+= x += 5
-= x -= 5

⚖ Comparison Operators

Comparison operators compare two values and return true or false.

  • == Equal to
  • === Strict equal to
  • != Not equal
  • > Greater than
  • < Less than

💻 Comparison Example


let age = 20;

console.log(age >= 18);

🔗 Logical Operators

Logical operators are used to combine multiple conditions.

Operator Meaning
&& AND
|| OR
! NOT

🔄 Increment & Decrement Operators

These operators increase or decrease a value by one. 


let count = 5;

count++;

count--;

❌ Common Mistakes

  • Using = instead of == for comparison
  • Forgetting operator symbols
  • Using wrong operator for calculation
  • Confusing && and ||

🎤 Interview Questions

Q1: What are JavaScript Operators?
Operators are symbols used to perform operations on values.

Q2: Which operator is used for addition?
+ operator

Q3: Difference between == and ===?
== checks value while === checks value and data type.

Q4: Name any two logical operators.
&& and ||

Assignment: =, +=, -=
