CSS Selectors

Learn different CSS selectors including Element, Class, ID and Universal selectors.

💡 Did You Know?

CSS Selectors are the foundation of CSS because they allow developers to choose exactly which HTML elements should be styled.

📖 What are CSS Selectors?

CSS Selectors are patterns used to select HTML elements. They tell the browser which elements should receive CSS styles.

🎯 Why do we use CSS Selectors?

  • Select specific HTML elements
  • Apply styles to webpages
  • Create organized CSS code
  • Reduce repeated styling
  • Improve website design

⭐ Types of CSS Selectors

Selector Description
Universal Selector (*) Selects all HTML elements
Element Selector Selects elements using tag name
Class Selector (.class) Selects elements with a specific class
ID Selector (#id) Selects one unique element
Group Selector Selects multiple elements together

📝 CSS Selector Syntax

The basic syntax of a CSS Selector is: 


selector{

property:value;

}

💻 Examples of CSS Selectors

1. Universal Selector


*{

margin:0;

padding:0;

}

This applies styles to all HTML elements.

2. Element Selector


p{

color:blue;

}

This changes the color of all paragraph elements.

3. Class Selector


.title{

color:red;

}

Class selector is used with a dot (.) and can be applied to multiple elements.

4. ID Selector


#header{

background:black;

}

ID selector is used with # and targets one unique element.

⚠ Common Mistakes

  • Using # instead of . for class selector
  • Using duplicate IDs
  • Writing incorrect selector names
  • Applying styles to wrong elements

🌍 Real Life Uses

  • Designing navigation menus
  • Styling buttons
  • Creating website layouts
  • Changing text appearance
  • Designing responsive websites
