💡 Did You Know?

JavaScript was created by Brendan Eich in 1995. It is one of the most popular programming languages used for web development.

⚡ Introduction to JavaScript

JavaScript is a programming language used to make websites interactive. It adds dynamic features like animations, buttons, form validation and interactive content.

📝 What is JavaScript?

JavaScript is a scripting language that runs inside web browsers. It works together with HTML and CSS to create modern web applications.

⭐ Features of JavaScript

  • Easy to Learn
  • Runs in All Modern Browsers
  • Makes Websites Interactive
  • Supports Object-Oriented Programming
  • Works with HTML and CSS

📌 Variables & Data Types

Variables are used to store information in JavaScript. JavaScript has different types of data values.

  • String
  • Number
  • Boolean
  • Array
  • Object
  • Undefined

💻 Example

let name = "Noor";

let age = 20;

let isStudent = true;

⚙ Functions in JavaScript

Functions are reusable blocks of code that perform a specific task. They help developers write clean and organized programs.

Example

function greet(){

console.log("Hello Noor");

}

🔄 Loops in JavaScript

Loops are used to repeat a block of code multiple times. Common loops are:

  • for loop
  • while loop
  • do while loop

🌐 DOM Manipulation

DOM (Document Object Model) allows JavaScript to access and modify HTML elements dynamically.

Example

document.getElementById("heading");

🎯 JavaScript Events

Events are actions performed by users on a webpage.

  • Click Event
  • Submit Event
  • Change Event
  • Mouseover Event
  • Keyboard Event

🚀 ES6 Features

  • let and const
  • Arrow Functions
  • Template Literals
  • Classes
  • Modules

🎯 JavaScript Interview Questions

Q1: What is JavaScript?
JavaScript is a programming language used to create interactive websites.

Q2: What are variables?
Variables store data values in a program.

Q3: What is DOM?
DOM allows JavaScript to interact with HTML elements.

Q4: Difference between let and const?
let value can be changed while const value cannot be reassigned.
