📘 HTML Chapter 4

HTML Tables & Lists

Learn HTML Tables, Lists and their different types with simple examples.

💡 Did You Know?

HTML Tables organize data into rows and columns, while HTML Lists help display related items in a structured way.

📖 What are HTML Lists?

HTML Lists are used to display multiple related items in an organized format. There are three types of HTML Lists.

📚 Types of HTML Lists

List Type Tag
Ordered List <ol>
Unordered List <ul>
Description List <dl>

📝 Ordered List Example


<ol>

<li>HTML</li>

<li>CSS</li>

<li>JavaScript</li>

</ol>

📝 Unordered List Example


<ul>

<li>Apple</li>

<li>Banana</li>

<li>Orange</li>

</ul>

📝 Description List Example


<dl>

<dt>HTML</dt>

<dd>Markup Language</dd>

</dl>

📖 What is an HTML Table?

An HTML Table is used to display information in rows and columns.

⭐ Important Table Tags

Tag Purpose
<table> Create Table
<tr> Table Row
<th> Table Heading
<td> Table Data

💻 Table Example


<table>

<tr>

<th>Name</th>

<th>Age</th>

</tr>

<tr>

<td>Noor</td>

<td>20</td>

</tr>

</table>

🎯 Advantages

  • Display data clearly
  • Organize information
  • Easy to read
  • Create menus using lists
  • Improve webpage structure

❌ Common Mistakes

  • Forgetting to close table tags
  • Using td instead of th for headings
  • Incorrect nesting of rows
  • Missing li tags inside lists

🎤 Interview Questions

Q1: How many types of HTML Lists are there?
Three (Ordered, Unordered and Description).

Q2: Which tag creates an Ordered List?
<ol>

Q3: Which tag creates a table row?
<tr>

Q4: Which tag is used for table headings?
<th>

⚡ Quick Revision

Ordered List: <ol>
Unordered List: <ul>
Table: <table>
Row & Data: <tr>, <td>, <th>
