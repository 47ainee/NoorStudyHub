💡 Did You Know?

HTML was created by Tim Berners-Lee in 1991. Today, every website on the internet uses HTML.

📖 HTML Introduction

HTML (HyperText Markup Language) is the standard language used to create web pages. It provides the basic structure of every website using tags and elements.

📝 What is HTML?

HTML is not a programming language. It is a markup language used to organize text, images, links, tables and forms on a webpage.

⭐ Features of HTML

  • Easy to Learn
  • Platform Independent
  • Supported by all Browsers
  • Works with CSS & JavaScript
  • Free to Use

💻 Example

<!DOCTYPE html>
<html>
<head>
<title>My Website</title>
</head>
<body>

<h1>Hello Noor!</h1>

</body>
</html>

📑 HTML Document Structure

Every HTML document follows a basic structure. It starts with <!DOCTYPE html>, followed by the <html>, <head>, and <body> tags.

Basic Structure

<!DOCTYPE html>
<html>

<head>
    <title>My Website</title>
</head>

<body>

    Content goes here

</body>

</html>

📝 Headings and Paragraphs

HTML provides six heading tags, from <h1> to <h6>. The <h1> tag is the largest heading, while <h6> is the smallest.

The <p> tag is used to create paragraphs and display normal text on a webpage.

Example

<h1>Main Heading</h1>

<h2>Sub Heading</h2>

<p>This is a paragraph.</p>

📋 HTML Lists

HTML provides different types of lists to organize information clearly. The main types are Ordered Lists, Unordered Lists and Description Lists.

1️⃣ Ordered List

An ordered list displays items with numbers. It uses the <ol> tag. 

<ol>
    <li>HTML</li>
    <li>CSS</li>
    <li>JavaScript</li>
</ol>

2️⃣ Unordered List

An unordered list displays items with bullet points. It uses the <ul> tag. 

<ul>
    <li>HTML</li>
    <li>CSS</li>
    <li>JavaScript</li>
</ul>

💡 Exam Tip

Remember:
• <ol> = Numbered List
• <ul> = Bullet List
• <li> = List Item

🔗 HTML Links

HTML links are created using the <a> tag. They allow users to navigate from one webpage to another.

Example

<a href="https://www.google.com">
Visit Google
</a>

🖼️ HTML Images

Images are displayed using the <img> tag. The src attribute specifies the image path, while alt provides alternative text.

Example

<img src="image.jpg"
alt="Nature Image"
width="300">

💡 Exam Tip

href → Link address
src → Image location
alt → Alternative text if image cannot load

📊 HTML Tables

HTML tables are used to display data in rows and columns. The main tags used are <table>, <tr>, <th> and <td>.

Example

<table border="1">

<tr>
    <th>Name</th>
    <th>Age</th>
</tr>

<tr>
    <td>Noor</td>
    <td>20</td>
</tr>

</table>

💡 Exam Tip

<table> = Creates a table
<tr> = Table Row
<th> = Table Heading
<td> = Table Data

📝 HTML Forms

HTML forms are used to collect information from users. They are commonly used for login pages, registration forms, contact forms and surveys.

Example

<form>

<label>Name:</label>
<input type="text">

<br><br>

<label>Email:</label>
<input type="email">

<br><br>

<input type="submit" value="Submit">

</form>

Common Input Types

  • text
  • email
  • password
  • number
  • radio
  • checkbox
  • date
  • file
  • submit

💡 Exam Tip

<form> = Creates a form
<input> = Takes user input
<label> = Displays field name
type = Defines the input type

🏷️ Semantic HTML

Semantic HTML uses meaningful tags that clearly describe the purpose of different parts of a webpage. It improves readability, SEO and accessibility.

Common Semantic Tags

  • <header> → Page Header
  • <nav> → Navigation Menu
  • <main> → Main Content
  • <section> → Section of Content
  • <article> → Independent Article
  • <footer> → Page Footer

🚀 HTML5 Features

  • Supports Audio & Video
  • Semantic Tags
  • Canvas for Graphics
  • Better Forms
  • Local Storage
  • Cross-platform Support

💡 Exam Tip

HTML5 is the latest version of HTML and provides many modern features for web development.

🎯 Interview Questions

Q1: What is HTML?

Answer: HTML is the standard markup language used to create web pages.

Q2: What is the difference between HTML and HTML5?

Answer: HTML5 provides new semantic tags, multimedia support, canvas, local storage and improved forms.

Q3: What are semantic tags?

Answer: Semantic tags clearly describe the purpose of webpage content, such as <header>, <section> and <footer>.
