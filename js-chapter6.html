JavaScript Events

Learn JavaScript Events, Event Listeners and User Interactions with practical examples.

💡 Did You Know?

Almost every interactive website uses JavaScript Events to respond to user actions.

📖 What are JavaScript Events?

JavaScript Events are actions performed by users or browsers. Events allow websites to respond when users click, type, scroll or move the mouse.

⭐ Why do we use Events?

  • Make websites interactive
  • Respond to user actions
  • Handle forms
  • Create dynamic webpages
  • Improve user experience

🎯 Common JavaScript Events

Event Description
click Occurs when user clicks
dblclick Double click event
mouseover Mouse moves over element
mouseout Mouse leaves element
keydown Key is pressed
keyup Key is released
submit Form submission
change Input value changes

💻 Click Event Example

🎯 Event Listener

Event Listeners are the modern way to handle events. 


document.getElementById("btn")

.addEventListener("click",function(){

alert("Button Clicked");

});

⌨ Keyboard Event


document.addEventListener("keydown",function(){

console.log("Key Pressed");

});

🖱 Mouse Event


document.getElementById("box")

.onmouseover=function(){

console.log("Mouse Enter");

}

📋 Form Event


document.querySelector("form")

.addEventListener("submit",function(){

alert("Form Submitted");

});

⭐ Advantages

  • Interactive webpages
  • Better user experience
  • Dynamic content
  • Real-time responses
  • Modern web applications

❌ Common Mistakes

  • Wrong event name
  • Missing function brackets
  • Selecting wrong element
  • Writing JavaScript before HTML loads
