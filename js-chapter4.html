Functions

Learn JavaScript functions, parameters, return values and examples.

💡 Did You Know?

Functions help programmers write reusable code and avoid repeating the same instructions.

📖 What are Functions?

A function is a reusable block of code that performs a specific task. Functions help organize programs and make code easier to understand.

⭐ Why do we use Functions?

  • Reuse code multiple times
  • Reduce code repetition
  • Make programs organized
  • Improve code readability

📝 Creating a Function


function greet(){

console.log("Hello World");

}

▶ Calling a Function

A function runs when we call its name. 


greet();

📌 Function Parameters

Parameters are values passed inside a function to perform operations. 


function welcome(name){

console.log("Hello " + name);

}

welcome("Noor");

🔙 Return Statement

The return statement sends a value back from a function. 


function add(a,b){

return a+b;

}

⚡ Arrow Functions

Arrow functions are a shorter way to write functions introduced in ES6. 


const add = (a,b) => {

return a+b;

};

❌ Common Mistakes

  • Calling function before creating it
  • Missing brackets
  • Using wrong parameters
  • Forgetting return statement
