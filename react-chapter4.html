Props & State

Learn React Props and State, their differences and how data is managed in React components.

💡 Did You Know?

Props are used to pass data from one component to another, while State stores data that can change inside a component.

📖 What are Props?

Props (Properties) are used to pass data from a parent component to a child component. Props are read-only, which means they cannot be modified by the child component.

💻 Props Example


function Welcome(props){

return 
Hello {props.name}
;

}

📖 What is State?

State is used to store data inside a component. Unlike Props, State can change during program execution.

💻 State Example


const [count,setCount] = useState(0);

⭐ Difference Between Props & State

Props State
Passed from Parent Managed inside Component
Read Only Can Change
Cannot Modify Can Update
Used for Communication Used for Dynamic Data

🎯 Why do we use Props?

  • Pass data
  • Reuse components
  • Keep code organized
  • Improve communication between components

🎯 Why do we use State?

  • Store changing values
  • Update UI automatically
  • Handle user interaction
  • Manage application data

⭐ Advantages

  • Reusable components
  • Dynamic user interface
  • Better data management
  • Clean code structure
  • Easy maintenance

❌ Common Mistakes

  • Trying to modify Props
  • Using State without useState()
  • Confusing Props with State
  • Updating State directly
