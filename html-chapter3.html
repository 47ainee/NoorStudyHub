📘 HTML Chapter 3

HTML Forms & Input Fields

Learn HTML Forms, Input Fields and Form Elements with easy explanations and examples.

💡 Did You Know?

HTML Forms are used to collect user information like Name, Email, Password and Feedback. Almost every website uses HTML Forms.

📖 What is an HTML Form?

An HTML Form is used to collect data from users. The collected information can be sent to a server for processing.

📝 Basic Form Syntax


<form>

</form>

📖 Common Form Elements

Element Purpose
<form> Create Form
<input> Take User Input
<label> Display Field Label
<textarea> Multi-line Text
<select> Dropdown List
<option> Dropdown Option
<button> Create Button

📚 Common Input Types

  • text
  • password
  • email
  • number
  • date
  • radio
  • checkbox
  • file
  • submit

💻 Example Form


<form>

<label>Name</label>

<input type="text">

<br>

<label>Email</label>

<input type="email">

<br>

<label>Password</label>

<input type="password">

<br>

<input type="submit" value="Submit">

</form>

⭐ Advantages of HTML Forms

  • Collect user information
  • Create Login Pages
  • Create Registration Forms
  • Collect Feedback
  • Easy to use

❌ Common Mistakes

  • Forgetting the name attribute
  • Using wrong input type
  • Missing label tags
  • Not closing form properly

🎤 Interview Questions

Q1: What is an HTML Form?
An HTML Form is used to collect user data.

Q2: Which tag creates a form?
<form>

Q3: Which tag is used for user input?
<input>

Q4: Name four input types.
text, email, password, checkbox

⚡ Quick Revision

Form Tag: <form>
Input Tag: <input>
Used For: Collecting User Data
Popular Types: text, email, password, radio
