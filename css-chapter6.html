🎨 CSS Chapter 6

Flexbox

Learn modern Flexbox layout to build responsive webpages easily.

💡 Did You Know?

Flexbox was introduced in CSS3 to make webpage layouts easier and more responsive without using floats.

📖 What is Flexbox?

Flexbox (Flexible Box Layout) is a CSS layout model used to arrange items in rows or columns. It makes it easy to align, distribute and organize elements on a webpage.

🎯 Why do we use Flexbox?

  • Create responsive layouts
  • Align items easily
  • Reduce CSS code
  • Build modern websites
  • Improve webpage design

⭐ Important Flexbox Properties

Property Purpose
display:flex Creates a flex container
flex-direction Sets row or column layout
justify-content Aligns items horizontally
align-items Aligns items vertically
gap Adds space between items
flex-wrap Moves items to next line

💻 Example


.container{

display:flex;

justify-content:center;

align-items:center;

gap:20px;

}

📚 Common Values

Property Values
flex-direction row, column
justify-content center, space-between, space-around
align-items center, flex-start, flex-end

🎯 Advantages

  • Easy alignment
  • Responsive design
  • Less CSS code
  • Professional layouts
  • Works on all modern browsers

❌ Common Mistakes

  • Forgetting display:flex
  • Confusing justify-content and align-items
  • Not using flex-wrap when needed
  • Applying Flexbox to the wrong element

🎤 Interview Questions

Q1: What is Flexbox?
Flexbox is a CSS layout model used for arranging webpage elements.

Q2: Which property creates a Flexbox container?
display:flex

Q3: Which property aligns items horizontally?
justify-content

Q4: Which property aligns items vertically?
align-items
