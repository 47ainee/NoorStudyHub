CSS Grid

Learn CSS Grid system for creating professional webpage layouts.

💡 Did You Know?

CSS Grid is one of the most powerful layout systems in CSS. It allows developers to create professional two-dimensional webpage layouts.

📖 What is CSS Grid?

CSS Grid is a layout system used to organize webpage elements into rows and columns. It helps create modern, responsive and professional webpage designs.

🎯 Why do we use CSS Grid?

  • Create complex layouts easily
  • Arrange items in rows and columns
  • Build responsive websites
  • Reduce layout code
  • Improve webpage structure

⭐ Important CSS Grid Properties

Property Purpose
display:grid Creates a Grid container
grid-template-columns Defines number of columns
grid-template-rows Defines number of rows
gap Adds space between grid items
justify-items Aligns items horizontally
align-items Aligns items vertically

💻 Example


.container{

display:grid;

grid-template-columns:1fr 1fr 1fr;

gap:20px;

}

📚 Common Grid Properties

Property Example
grid-template-columns 1fr 1fr 1fr
grid-template-rows 100px 100px
gap 20px
grid-column 1 / 3
grid-row 1 / 2

🎯 Advantages

  • Professional layouts
  • Easy row and column management
  • Responsive design
  • Less CSS code
  • Easy alignment

❌ Common Mistakes

  • Forgetting display:grid
  • Incorrect column values
  • Ignoring gap property
  • Using Grid where Flexbox is better
