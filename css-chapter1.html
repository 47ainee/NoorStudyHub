🎨 CSS Chapter 1

Introduction to CSS

Learn CSS basics, syntax, types and how CSS styles webpages with easy examples.

💡 Did You Know?

CSS was introduced in 1996 by the World Wide Web Consortium (W3C) to separate webpage design from HTML structure.

📖 What is CSS?

CSS stands for Cascading Style Sheets. It is used to style HTML webpages by changing colors, fonts, layouts, spacing and animations. CSS makes webpages attractive and responsive.

🎯 Why do we use CSS?

  • Add colors to webpages
  • Change fonts and text styles
  • Create responsive layouts
  • Add animations and effects
  • Improve user experience

⭐ Features of CSS

  • Easy to Learn
  • Reusable Styles
  • Responsive Design
  • Improves Website Appearance
  • Works with HTML and JavaScript

📑 CSS Syntax


selector {

property: value;

}

Example:

h1{

color:blue;

font-size:40px;

}

📚 Types of CSS

Type Description
Inline CSS Written inside HTML tag using style attribute
Internal CSS Written inside <style> tag
External CSS Written in separate .css file

💻 Example


h1{

color:red;

}

p{

font-size:20px;

}

🎯 Advantages of CSS

  • Professional webpage design
  • Less code repetition
  • Easy maintenance
  • Fast webpage loading
  • Responsive websites

❌ Limitations of CSS

  • Different browser support
  • Complex layouts need practice
  • Animations may affect performance

🎤 Interview Questions

Q1: What is CSS?
CSS is used to style HTML webpages.

Q2: What is the full form of CSS?
Cascading Style Sheets.

Q3: How many types of CSS are there?
Three: Inline, Internal and External.

Q4: Which CSS type is most recommended?
External CSS.
