CSS Box Model

Learn Margin, Border, Padding, Width and Height with practical examples.

💡 Did You Know?

Every HTML element is treated as a rectangular box in CSS. This is called the CSS Box Model.

📖 What is CSS Box Model?

The CSS Box Model is used to understand how much space an HTML element occupies. Every element consists of Content, Padding, Border and Margin.

🎯 Parts of CSS Box Model

Part Description
Content Main text or image inside the element
Padding Space between content and border
Border Line around the padding
Margin Outer space outside the border

📦 Box Model Structure


Margin

 Border

  Padding

   Content

💻 Example


div{

width:300px;

padding:20px;

border:2px solid black;

margin:30px;

}

⭐ Important Properties

Property Purpose
width Sets element width
height Sets element height
padding Inner spacing
border Creates border
margin Outer spacing

🎯 Advantages

  • Creates proper spacing
  • Improves webpage layout
  • Makes design clean
  • Easy element positioning
  • Professional webpage appearance

❌ Common Mistakes

  • Confusing padding with margin
  • Ignoring border size
  • Using too much margin
  • Incorrect width calculations

🎤 Interview Questions

Q1: What are the four parts of the CSS Box Model?
Content, Padding, Border and Margin.

Q2: Which property creates inner spacing?
padding

Q3: Which property creates outer spacing?
margin

Q4: Which property draws a line around an element?
border

⚡ Quick Revision
