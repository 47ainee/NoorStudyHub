🎨 CSS Chapter 9

Animations & Transitions

Learn CSS animations, transitions and transform effects with examples.

💡 Did You Know?

CSS Animations and Transitions make websites more interactive without using JavaScript.

📖 What are CSS Animations & Transitions?

CSS Transitions create smooth changes between two states of an element. CSS Animations create moving effects by changing CSS properties over time. They improve the appearance and user experience of a website.

🎯 Why do we use Animations?

  • Create attractive websites
  • Improve user experience
  • Highlight important elements
  • Provide smooth visual effects
  • Increase user engagement

⭐ Transition Properties

Property Purpose
transition-property Selects property to animate
transition-duration Animation time
transition-delay Starts animation after delay
transition-timing-function Controls animation speed

⭐ Animation Properties

Property Purpose
animation-name Name of animation
animation-duration Animation time
animation-delay Delay before animation starts
animation-iteration-count Number of repetitions
animation-direction Animation direction

💻 Transition Example


button{

background:blue;

transition:0.5s;

}

button:hover{

background:red;

}

💻 Animation Example


@keyframes move{

from{

left:0;

}

to{

left:200px;

}

}

.box{

animation:move 2s infinite;

}

🎯 Advantages

  • Professional design
  • Smooth effects
  • Better user experience
  • Interactive webpages
  • No JavaScript required for simple effects

❌ Common Mistakes

  • Using too many animations
  • Very long animation duration
  • Forgetting @keyframes
  • Overusing animation effects
