💡 Did You Know?

CSS was created by Håkon Wium Lie in 1996. It is used to style and design web pages.

🎨 Introduction to CSS

CSS (Cascading Style Sheets) is a styling language used to make web pages beautiful and attractive. It controls colors, fonts, layouts, spacing and responsive designs.

📝 What is CSS?

CSS is used together with HTML to improve the appearance of websites. HTML creates the structure, while CSS controls the presentation and design.

⭐ Features of CSS

  • Separates content from design
  • Creates attractive web pages
  • Supports responsive design
  • Provides animations and transitions
  • Works with HTML and JavaScript

💡 Did You Know?

CSS was created by Håkon Wium Lie in 1996. CSS is used to style and design modern websites.

🎨 Introduction to CSS

CSS (Cascading Style Sheets) is a styling language used to control the appearance of web pages. It is used for colors, fonts, layouts, spacing and responsive designs.

📝 What is CSS?

CSS works with HTML to make websites attractive and user-friendly. HTML creates the structure of a webpage, while CSS controls its design.

⭐ Features of CSS

  • Separates content from design
  • Creates beautiful layouts
  • Supports responsive websites
  • Adds animations and transitions
  • Works with HTML and JavaScript

📌 Types of CSS

There are three main types of CSS:

  • Inline CSS: CSS written inside an HTML element.
  • Internal CSS: CSS written inside the style tag.
  • External CSS: CSS written in a separate CSS file.

🎯 CSS Selectors

CSS selectors are used to select HTML elements and apply styles to them.

Examples

p {
 color: blue;
}

.heading {
 font-size: 30px;
}

#box {
 background: red;
}

📦 CSS Box Model

Every HTML element is considered a box. CSS box model consists of:

  • Content
  • Padding
  • Border
  • Margin

🧩 Flexbox

Flexbox is a CSS layout system used to arrange elements in rows or columns. It helps create flexible and responsive designs.

Common Flexbox Properties

  • display:flex
  • justify-content
  • align-items
  • flex-direction

🔲 CSS Grid

CSS Grid is a layout system used to create complex webpage layouts using rows and columns.

✨ CSS Animations

CSS animations allow elements to change their style gradually without using JavaScript.

📱 Responsive Design

Responsive design makes websites work properly on mobile phones, tablets and desktop screens. Media queries are commonly used for responsive designs.

🎯 CSS Interview Questions

Q1: What is CSS?

Q3: What is Flexbox?
Flexbox is a CSS layout system used for arranging elements easily.
