🎨 CSS Chapter 3

Colors & Backgrounds

Learn CSS colors, background colors, images, gradients and opacity with examples.

💡 Did You Know?

CSS provides more than 140 predefined color names and also supports HEX, RGB, RGBA and HSL color formats.

📖 What are CSS Colors?

CSS Colors are used to change the color of text, backgrounds, borders and other webpage elements. Colors make websites attractive and improve user experience.

🎯 Why do we use Colors & Backgrounds?

  • Improve webpage appearance
  • Highlight important content
  • Create attractive designs
  • Increase readability
  • Build professional websites

⭐ Common Color Formats

Format Example
Color Name red
HEX #ff0000
RGB rgb(255,0,0)
RGBA rgba(255,0,0,0.5)
HSL hsl(0,100%,50%)

📝 Background Properties

Property Purpose
background-color Sets background color
background-image Adds background image
background-repeat Controls image repeating
background-size Controls image size
background-position Sets image position

💻 Example


body{

background-color:lightblue;

}

h1{

color:darkblue;

}

div{

background-color:yellow;

}

🎯 Advantages

  • Beautiful webpage design
  • Easy customization
  • Professional appearance
  • Improves readability
  • Better user experience

❌ Common Mistakes

  • Using too many bright colors
  • Poor text and background contrast
  • Wrong HEX values
  • Large background images

🎤 Interview Questions

Q1: Which property changes text color?
color

Q2: Which property changes background color?
background-color

Q3: Name three CSS color formats.
HEX, RGB and HSL

Q4: Which property adds a background image?
background-image
