Display & Position

Learn Display properties, Position types and webpage layouts in CSS.

💡 Did You Know?

The CSS display property controls how an element appears on a webpage, while the position property controls where it appears.

📖 What is Display in CSS?

The display property defines how an HTML element is displayed on the webpage. Different display values help create different webpage layouts.

⭐ Common Display Values

Display Value Description
block Takes full width of the page
inline Takes only required width
inline-block Inline element with block features
none Hides the element
flex Creates flexible layouts
grid Creates grid layouts

📖 What is Position in CSS?

The position property controls the location of an HTML element on a webpage.

⭐ Types of Position

Position Description
static Default position
relative Moves relative to its original position
absolute Moves relative to its parent element
fixed Stays fixed while scrolling
sticky Acts like relative then fixed

💻 Example


.box{

display:block;

position:relative;

top:20px;

left:30px;

}

🎯 Advantages

  • Creates professional layouts
  • Easy element positioning
  • Improves webpage design
  • Responsive layouts
  • Better user experience

❌ Common Mistakes

  • Using absolute without parent position
  • Confusing block and inline
  • Overusing fixed position
  • Ignoring z-index

🎤 Interview Questions

Q1: Which property controls element visibility?
display

Q2: Which display value hides an element?
display:none

Q3: Which position stays fixed while scrolling?
fixed

Q4: Name any four position values.
static, relative, absolute, fixed

⚡ Quick Revision

Display: block, inline, flex
Hide Element: display:none
Position: static, relative, absolute
Fixed: Stays on screen while scrolling
