⚡ JavaScript Chapter 1

Introduction to JavaScript

Learn JavaScript basics, syntax and important concepts with easy examples.

💡 Did You Know?

JavaScript was created by Brendan Eich in 1995. It became one of the most important languages for making websites interactive.

⚡ What is JavaScript?

JavaScript is a programming language used to make web pages interactive and dynamic. It works together with HTML and CSS to create modern websites and web applications.

🎯 Why do we use JavaScript?

  • Create interactive websites
  • Add animations and effects
  • Handle user actions
  • Validate forms
  • Change webpage content dynamically

⭐ Features of JavaScript

  • Easy to Learn
  • Runs in Web Browsers
  • Makes Websites Interactive
  • Supports Object-Oriented Programming
  • Works with HTML and CSS

📝 JavaScript Syntax

JavaScript syntax defines the rules for writing JavaScript code. A JavaScript statement usually ends with a semicolon. 


let message = "Hello JavaScript";

console.log(message);

💻 First JavaScript Program

The following example displays a message in the browser console. 


console.log("Hello World");

📌 Adding JavaScript to HTML

JavaScript can be added inside HTML using the script tag. 


<script>

alert("Welcome to JavaScript");

</script>

🌐 Where JavaScript Runs?

  • Web Browsers
  • Servers using Node.js
  • Mobile Applications
  • Desktop Applications

❌ Common Mistakes

  • Writing incorrect syntax
  • Missing brackets
  • Using wrong variable names
  • Ignoring case sensitivity
